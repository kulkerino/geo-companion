# 2026-10-26 — Model M1c: real training on the RTX 3060 PC

## Intent

Run M1c by hand on kulo's Windows desktop, following
[`docs/runbook-m1c-rtx-3060.md`](../docs/runbook-m1c-rtx-3060.md): set up, fetch the full
OSV-5M slice, prove the GPU path with a smoke run, then train overnight.

## Evidence

- Commit: `bf0c931` (abstention threshold fix).
- Machine: Windows 11, NVIDIA GeForce RTX 3060 **12 GB** (driver 610.88), 12 CPU threads,
  15.9 GB RAM. Repository clone at `C:\Users\kulo\Documents\geolearn`.
- Commands and results:
  - `uv sync --group training` → `torch 2.11.0+cu128`, `torch.cuda.is_available()` is `True`,
    device `NVIDIA GeForce RTX 3060`.
  - `uv run pytest -q packages/training` → 44 passed.
  - `geo-train fetch --train-shards 0-9 --test-shards 0-4 --delete-archives`, then
    `--train-shards 10-19 --test-shards ""` (run in two halves because C: had 42 GB free at
    first; kulo then freed space to 286 GB). Result: 1,000,000 train photos and metadata
    rows, 210,122 test photos. Hugging Face throughput was very uneven: a 2.5 GB shard took
    from about 1 to about 20 minutes.
  - Smoke run 1 (`--max-images 50000 --epochs 1 --workers 8`): one epoch in 159.9 s, val
    top-1 0.160 (majority baseline 0.264), then **crashed in `write_manifest`**: the model
    reached the 0.8 target precision at no threshold, `choose_threshold` returned the 1.01
    sentinel, and the manifest contract allows at most 1.
  - Fix: the never-answer threshold is now 1.0 (the model abstains unless its top-1
    probability is exactly 1). Training tests still pass (44) and ruff is clean.
  - Smoke run 2 (same, `--workers 11`): completed, epoch 164.9 s, manifest written with
    `abstain_below: 1.0`. `nvidia-smi dmon` showed 35–60% SM use while the page cache was
    cold, then 85–98% once warm. Loading the 2.9 GB `train.csv` takes about 3 minutes
    before training starts.
  - M1c run started at 19:13 local with the runbook command plus `--workers 11`, then
    **stopped by hand at about 19:23 local before epoch 1 finished**: kulo does not want the
    PC left on unattended and prefers to run it on a weekend when they are home. No M1c
    results exist yet.
- Decisions:
  - `--workers 11` instead of 8 (12 threads available); the GPU, not decoding, was the
    limit once warm.
- Limitations and external gaps:
  - Training cannot resume: an interruption loses the run (only `best.pt` weights are kept,
    no optimiser state).
  - Measured throughput (about 300 photos/s in the smoke run) is below the runbook
    estimate, so 16 epochs may take 10–15 hours rather than 6–9.
